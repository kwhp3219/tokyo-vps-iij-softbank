## 下单前必须确认的四件事

绿云东京套餐便宜是真的，但有几个限制写在条款和套餐说明里，很多推荐文章不会主动提：

1. **促销套餐不支持退款。** Premium KVM 补货款和历年促销款的页面都明确标注 "No refund/money back"。这意味着下单前机房、线路、计费周期三样都要核对清楚，选错了钱基本拿不回来。退款政策在常规款上如何执行，官方没有统一公开的说明，不确定的话开工单问清楚再付钱。
2. **CPU 是 fair-share 共享模式。** 包括周年促销款在内，绿云东京的核数都是 fair-share EPYC，不是独享核心。历史实测里这类机型的单核性能属于“够用”水平，重度计算任务别指望它，跑网站、代理、轻量开发环境没问题。
3. **晚高峰会有波动。** 第三方评测提到，东京机房白天非常顺畅，晚高峰丢包率会升高；电信表现整体较好，偏远地区另说。如果你的业务对晚高峰稳定性极其敏感，先月付验证一个月再考虑长期方案。
4. **测试 IP 不能混用。** 每个机房、每条线路的路由不同，测软银就用软银的 IP，测 IIJ 就用 IIJ 的 IP，拿其他机房的测试结果推断东京线路是不准的。

顺带说一句历史参考：2023 年有评测发现绿云某东京 IP 段（43.239.249.*）比较干净，可解锁日本 Netflix 和 Disney+。IP 会随分配轮换，这个结论放到现在未必成立，但能说明这家商家的 IP 池质量有过不错的记录，新开的机器如果 IP 不理想，可以开工单询问更换（该商家其他机房有付费换 IP 的先例，费用约 $3/次，东京是否同样执行需与客服确认）。

## 装好系统之后，先做这几件事

VPS 到手后别急着部署业务，先花十分钟把基础安全做了。这套流程来自通用的 VPS 安全建议，适用于包括绿云在内的所有 KVM 机型：

1. 修改 SSH 默认 22 端口——这是扫描机器人的第一目标，改掉能过滤掉绝大多数暴力破解。
2. 创建普通用户并配置 sudo，不要一直用 root 干活。
3. 配置防火墙，只开放必要端口。
4. 设置定期备份。绿云东京款每台附带 1 次免费 Backup/Snapshot 额度，管理面板是 VirtFusion，快照功能直接在面板里操作。
5. 记录套餐到期时间。VPS 到期不续费会直接删机，数据不等人。
